# VgScript example

A short two-scene story that uses every VgScript feature: speakers, talks,
decisions, conditions, facts, timers, events, parallel actions and a jump between
scenes. The VgScript plugin in the game engine ships it with its showcase
level. Read the scripts as a reference, or change them and watch the level
change with you.

You don't need git or any programming knowledge to edit them.

## What's here

| File | What it is |
| --- | --- |
| `Scenes.txt` | The scenes in play order. |
| `S1_Room.vgs` | Scene 1: Vee and Gee find their own script on a laptop. |
| `S2_End.vgs` | Scene 2: the end of the script. The first time, Vee and Gee start scene 1 over; the second time, they stay. |
| `*.vgs.meta` | Generated by the VgScript tools. Never edit them by hand. |

## Edit the story

1. Install the free **VgScript** extension for your editor. It's available for
   JetBrains IDEs (Rider, IntelliJ, WebStorm…) and VS Code; see
   [vgscript.com](https://vgscript.com). Any text editor works too; the extension adds
   highlighting, live checks and automatic numbering.
2. Open this folder in that editor and change any `.vgs` file.
3. Right-click the folder and run **VgScript → Fix + Reconcile All**. It numbers
   new entries and updates the `.meta` files. Without the extension, the game engine
   import does this for you.
4. Run **VgScript → Validate** to catch mistakes, and **VgScript → Travel** to
   walk every branch and find loose ends.

The same steps from a terminal: `vgs fix-all .`, `vgs check-all .`,
`vgs travel .`. In the engine, **Tools → VgScript → Install vgs Command-Line Tool**
puts `vgs` on your `PATH`.
